# PokeYudi
Jogo sem fins lucrativos
Este é um projeto independente feito de fã para fã,sem qualquer fim comercial ou lucrativo.
​Pokémon e todos os nomes, personagens e sprites relacionados são marcas registradas da Nintendo, Creatures Inc. e GAME FREAK inc. Os sprites utilizados neste projeto são carregados publicamente através do acervo da comunidade Pokémon Showdown.
